## How this project is checked

This project uses Python. The checks your work must pass are in the tests folder. Every time you push to GitHub, GitHub runs them for you (see the Actions tab), and your trainer sees the result beside the work you hand in.

Run the checks on your own computer before you push:

```
pip install -r requirements.txt
pytest -v
```

The checks fail at first: that is expected. Your job is to write the code that makes them pass. Do not change the tests.

## Handing in

1. Push your latest work to GitHub.
2. In your FesCode portal, open Courses, find the assignment, and paste the link to this repository.
3. The commit you hand in is the one your trainer marks. To update it, push again and hand in again.
